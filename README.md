# CampusHub Student Portal

A responsive student portal website made with HTML, CSS, and JavaScript.

## Included features
- Dashboard with overview cards
- Class schedule
- Grades and academic performance
- Announcements
- Student profile
- Responsive navigation and basic search

All student information is fictional sample data. The website is a static front-end demo and does not use a backend or database.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository (for example, `student-portal`).
2. Upload `index.html` (and this README if desired) to the repository's main branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages section and usually follows:
   `https://YOUR-USERNAME.github.io/student-portal/`

Replace `YOUR-USERNAME` with your GitHub username. Submit both the repository URL and the published Pages URL in Canvas.
